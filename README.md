# 定时消息推送（Cron）

一个基于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 的定时消息推送插件：用 cron 表达式（或「每日/每周」快捷语法）设置定时任务，到点后自动向群或私聊发送固定消息。

- ⏰ **cron 定时**：完整 5 段 cron 表达式（分 时 日 月 周），支持 `*`、`*/n`、`a-b`、`a,b,c`
- 🗓 **快捷语法**：`每日 08:30`、`每周一 09:00`，不用记 cron
- 🛠 **完整管理**：列表、手动测试、暂停、恢复、删除、**编辑内容**、**改触发时间**
- 🕐 **触发信息**：列表显示上次/下次触发时间与**累计触发次数**
- 🛡 **自动停用**：连续发送失败达到阈值自动暂停任务并**发消息提醒**，避免无效重试刷屏
- 🔐 **权限控制**：管理命令仅**管理员**可用，且只能操作**本会话**的任务
- ✨ **占位符**：消息支持 `{{time}}`、`{{date}}`、`{{datetime}}`、`{{at:QQ号}}`
- 🔁 **离线补发**：可选开启，插件启动时补发离线期间错过的任务
- 💬 **群聊 + 私聊**：两个场景都能用，任务推送到创建它的会话
- 💾 **任务持久化**：使用 AstrBot KV 存储，重启不丢失
- 🌏 **时区可配**：Docker 部署（默认 UTC）可配置 `Asia/Shanghai` 等时区
- 纯命令实现，**不依赖 LLM**，装上即用

## 安装

1. 在 AstrBot 插件市场搜索「定时消息推送」安装，或克隆本仓库放入 `AstrBot/data/plugins/`。
2. 在 WebUI 插件页点击「重载插件」，确认加载成功。
3. （可选）在插件配置中设置时区，例如 `Asia/Shanghai`。

## 使用

| 指令 | 说明 |
| --- | --- |
| `/定时 新增 <时间>|<消息>` | 创建定时任务，例：`/定时 新增 每日 08:00|早上好，记得喝水哦` |
| `/定时 列表` | 查看本会话任务（含上次/下次触发时间与累计次数） |
| `/定时 编辑 <编号>|<新内容>` | 修改任务的消息内容 |
| `/定时 改时 <编号>|<新时间>` | 修改任务的触发时间 |
| `/定时 立即 <编号>` | 手动触发一次（测试用） |
| `/定时 暂停 <编号>` | 暂停任务 |
| `/定时 启用 <编号>` | 恢复任务 |
| `/定时 删除 <编号>` | 删除任务 |
| `/定时 帮助` | 查看帮助 |

> 🔐 权限说明：`新增 / 编辑 / 改时 / 立即 / 暂停 / 启用 / 删除` 等管理命令需要**机器人管理员权限**（非管理员会被拒绝），可防止群内成员滥用刷屏或互相删任务。`列表 / 帮助` 对所有群成员开放。
>
> 🔒 会话归属：管理命令只能操作**本会话创建的任务**。在 A 群用 `/定时 删除 1` 不会误删 B 群的任务；如确需跨会话管理，可开启配置 `allow_cross_session`。
>
> 📋 列表默认只显示**当前会话**的任务；如需查看所有会话，请在插件配置中开启 `list_global`。
>
> 💬 群聊与私聊均可使用，任务会推送到创建它的那个会话。

### 消息占位符

发送时会自动替换以下占位符：

| 占位符 | 说明 | 示例 |
| --- | --- | --- |
| `{{time}}` | 当前时间 HH:MM | `08:00` |
| `{{date}}` | 今日日期 YYYY-MM-DD | `2026-09-25` |
| `{{datetime}}` | 日期+时间 | `2026-09-25 08:00` |
| `{{at:QQ号}}` | 在消息中 @ 指定成员（需平台支持） | `{{at:10001}}` |

例：`/定时 新增 每日 08:00|早上好，今天是 {{date}}，现在 {{time}}`

值班提醒例：`/定时 新增 0 9 * * 1|{{at:10001}} 今天轮到你值班啦`

> `{{at:...}}` 依赖平台是否支持 @ 消息段（OneBot v11 等支持）。若平台不支持或构建失败，会自动降级为纯文本发送。

### 时间写法

```
/定时 新增 0 8 * * *|早安                 ← cron：每天 8:00
/定时 新增 */30 * * * *|该喝水了          ← cron：每 30 分钟
/定时 新增 0 9 * * 1|周一晨会             ← cron：每周一 9:00
/定时 新增 每日 08:30|早上好              ← 快捷语法
/定时 新增 每周五 17:00|下班打卡           ← 快捷语法
```

cron 5 段含义：`分 时 日 月 周`（周：0/7=周日，1-6=周一~周六）。

## 配置项

| 配置 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `check_interval_seconds` | int | 20 | 调度器检查频率（秒，最小 5 秒） |
| `max_tasks_per_group` | int | 10 | 单个会话最多任务数 |
| `max_total_tasks` | int | 50 | 全局任务总数上限 |
| `max_consecutive_failures` | int | 3 | 连续发送失败达到该次数自动暂停任务（0=不自动暂停） |
| `list_global` | bool | false | 开启后 `/定时 列表` 显示所有会话的任务（默认仅显示当前会话） |
| `allow_cross_session` | bool | false | 允许管理员跨会话操作任务（默认只能管理本会话的任务） |
| `catch_up` | bool | false | 插件启动时补发离线期间错过的任务（每个任务最多补发一次） |
| `catch_up_max_hours` | int | 6 | 补发窗口上限（小时） |
| `timezone` | string | 空 | 时区（IANA 格式，如 `Asia/Shanghai`）；留空用服务器本地时区 |

## 说明

- 定时消息属于**主动消息**，依赖平台是否支持主动推送（OneBot v11 / Telegram / Discord 等支持，详见 AstrBot 官方文档）。
- 任务按「分钟」粒度触发，实际发送时间与计划时间可能有至多一个检查周期的延迟（默认 20 秒内）。
- 若机器人正好在计划时刻离线：默认该分钟的任务会错过、不补发，恢复后从下一个匹配时间继续；开启 `catch_up` 后会在启动时补发一次。
- cron 的日字段与周字段**同时**被限定时，命中其一即触发（与标准 cron 行为一致）。例如 `0 9 1 * 1` 表示「每月 1 号或每周一 9:00」。
- 非法 cron（如 `0 25 * * *`）会在创建时直接报错，不会产生「永不触发」的静默任务。

## 开发

```
astrbot_plugin_cron_push/
├── metadata.yaml       # 插件元数据
├── main.py             # 插件入口（命令、调度循环、KV 持久化）
├── cron.py             # cron 表达式解析与匹配（可独立测试）
└── _conf_schema.json   # WebUI 配置面板
```

本地调试：将本目录放入 `AstrBot/data/plugins/`，启动 AstrBot 后在 WebUI 插件页「重载插件」。

## 更新日志

### v1.3.0
**问题修复**
- 🐞 **修复「指定日期」任务会每天触发**：周字段为 `*` 时被误判为「受限」，导致日字段受限的任务（如 `0 8 1 * *` 每月 1 号、`30 9 15 * *` 每月 15 号）实际**每天都发送**。现已按标准 cron 语义正确处理日/周字段。
- 🐞 **修复越界 cron 被静默接受**：`0 25 * * *`、`0 8 32 * *` 等原来不报错却**永不触发**（占用任务配额且无任何提示），现在创建时即报错并说明超范围。
- 🐞 **修复跨会话越权操作**：管理命令原来只校验编号存在，A 群管理员可用 `/定时 删除 1` 删掉 B 群的任务，甚至把内容发到 B 群；现在默认只能操作**本会话**的任务。
- 🐞 **修复消息空白被压扁**：消息内容中的连续空格、换行会被压缩成单个空格，导致**无法发送多行消息**；现已保留原文格式。
- 🐞 修复 `find_next` 逐分钟暴力扫描整年的性能问题：改为按天跳跃，最坏情况从约 0.07s 降至约 0.002s，并把搜索范围扩到 8 年以正确计算闰日（2/29）这类任务的下次触发时间。

**新增功能**
- 💬 **私聊支持**：群聊与私聊均可使用，任务推送到创建它的会话
- 🔁 **离线补发**：新增配置 `catch_up` / `catch_up_max_hours`，插件启动时补发离线期间错过的任务（每个任务最多补发一次，默认关闭）
- 🔔 **失败提醒**：任务因连续发送失败被自动暂停时，会向该会话发送提示消息
- ✨ **`{{at:QQ号}}` 占位符**：可在定时消息中 @ 指定成员（需平台支持，失败自动降级为纯文本）
- 🔒 新增配置 `allow_cross_session`（默认关闭），需要跨会话管理时可开启
