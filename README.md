# 定时群消息推送（Cron）

一个基于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 的定时消息推送插件：用 cron 表达式（或「每日/每周」快捷语法）设置定时任务，到点后自动向群发送固定消息。

- ⏰ **cron 定时**：完整 5 段 cron 表达式（分 时 日 月 周），支持 `*`、`*/n`、`a-b`、`a,b,c`
- 🗓 **快捷语法**：`每日 08:30`、`每周一 09:00`，不用记 cron
- 💾 **任务持久化**：使用 AstrBot KV 存储，重启不丢失
- 🛠 **完整管理**：列表、手动测试、暂停、恢复、删除
- 🌏 **时区可配**：Docker 部署（默认 UTC）可配置 `Asia/Shanghai` 等时区
- 纯命令实现，**不依赖 LLM**，装上即用

## 安装

1. 在 AstrBot 插件市场搜索「定时群消息推送」安装，或克隆本仓库放入 `AstrBot/data/plugins/`。
2. 在 WebUI 插件页点击「重载插件」，确认加载成功。
3. （可选）在插件配置中设置时区，例如 `Asia/Shanghai`。

## 使用

| 指令 | 说明 |
| --- | --- |
| `/定时 新增 <时间>|<消息>` | 创建定时任务，例：`/定时 新增 每日 08:00|早上好，记得喝水哦` |
| `/定时 列表` | 查看所有任务 |
| `/定时 立即 <编号>` | 手动触发一次（测试用） |
| `/定时 暂停 <编号>` | 暂停任务 |
| `/定时 启用 <编号>` | 恢复任务 |
| `/定时 删除 <编号>` | 删除任务 |
| `/定时 帮助` | 查看帮助 |

### 时间写法

```
/定时 新增 0 8 * * *|早安                 ← cron：每天 8:00
/定时 新增 */30 * * * *|该喝水了          ← cron：每 30 分钟
/定时 新增 0 9 * * 1|周一晨会             ← cron：每周一 9:00
/定时 新增 每日 08:30|早上好              ← 快捷语法
/定时 新增 每周五 17:00|下班打卡           ← 快捷语法
```

cron 5 段含义：`分 时 日 月 周`（周：0/7=周日，1-6=周一~周六）。

## 配置项

| 配置 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `check_interval_seconds` | int | 20 | 调度器检查频率（秒，最小 5 秒） |
| `max_tasks_per_group` | int | 10 | 单个群最多任务数 |
| `max_total_tasks` | int | 50 | 全局任务总数上限 |
| `timezone` | string | 空 | 时区（IANA 格式，如 `Asia/Shanghai`）；留空用服务器本地时区 |

## 说明

- 定时消息属于**主动消息**，依赖平台是否支持主动推送（OneBot v11 / Telegram / Discord 等支持，详见 AstrBot 官方文档）。
- 若机器人正好在计划时刻离线，该分钟的任务会错过、不补发；恢复后从下一个匹配时间继续。
- 任务按「分钟」粒度触发，实际发送时间与计划时间可能有至多一个检查周期的延迟（默认 20 秒内）。

## 开发

```
astrbot_plugin_cron_push/
├── metadata.yaml       # 插件元数据
├── main.py             # 插件入口（命令、调度循环、KV 持久化）
├── cron.py             # cron 表达式解析与匹配（可独立测试）
└── _conf_schema.json   # WebUI 配置面板
```

本地调试：将本目录放入 `AstrBot/data/plugins/`，启动 AstrBot 后在 WebUI 插件页「重载插件」。
